# Engram logo source notice

Engram's spark logo uses the original 1024×1024 Paper Muse vector artwork.
The same source was later preserved in Glaux Reader before that project
adopted its owl icon.

- Canonical Engram source: [`logo.svg`](logo.svg)
- Original Paper Muse source blob: `bf852ee94a56b87d309f5dd487bd943c498194a5`
- Glaux Reader preservation commit: `603d7354`
- Original project license: MIT
- Original project copyright: 2024 Stanford Open Virtual Assistant Lab

The generated PNG, ICNS, and ICO files in this repository are derivatives of
this vector source. Regenerate the Tauri set from `apps/desktop` with
`npm exec tauri icon -- ../../docs/logo.svg`; the web PNG and desktop favicon
are 512×512 and 128×128 renders of the same source.
